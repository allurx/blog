# allurx 的个人博客

记录和讲解计算机相关知识的个人博客，访问地址为 [blog.allurx.io](https://blog.allurx.io)。内容覆盖计算机基础、软硬件原理、开发实践及相关应用，每篇文章围绕一个明确的学习目标展开，并说明所需的前置知识。

文章以 Markdown 维护，构建时生成完整 HTML。网站支持搜索、主题切换、文章目录和代码复制，无 JavaScript 时仍可阅读、通过目录跳转和打印。

## 本地运行

安装 [.node-version](.node-version) 指定的 Node.js，在仓库根目录执行：

```sh
npm ci
npm run dev
```

打开终端输出的本地地址，修改文章或浏览器资源后会自动刷新。

## 使用与维护

| 要做的事 | 文档 |
| --- | --- |
| 新增或修订文章 | [写作指南](docs/writing.md)：文章格式、组织与表达、来源、示例及附件 |
| 修改网站 | [开发指南](docs/development.md)：构建过程、源码入口、验证与预览 |
| 发布网站 | [发布指南](docs/deployment.md)：自动发布、手动发布与结果查看 |
| 调整定时与手动写作 | [任务定义](automation/daily-blog.md)：生成频率、手动新增、失败恢复、内容去重与发布核验。执行日程在既有云端任务中维护 |

站点允许同一天发布多篇不同文章。定时每天一篇，手动每次额外新增一篇，两者分别计数；同一次执行的重试恢复原成果。文章主题与写作要求统一由写作指南维护。
